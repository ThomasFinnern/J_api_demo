### Pagination parameters (query- part)

Parameters: ->URI Query : ```?page[offset]="90"&page[limit]="30"``` can be used directly.  
Better encoded this parameters to ```?page%5Boffset%5D=90&page%5Blimit%5D=30```. 

Not usable: 
http:\/\/127.0.0.1\/api_6x\/api\/index.php\/v1\/config\/application?page\[offset\}="90"&page\[limit\]="30",  
usable: http:\/\/127.0.0.1\/api_6x\/api\/index.php\/v1\/config\/application?page%5Boffset%5D=90&page%5Blimit%5D=30",

if the '?' must be prepended after or may be prepended before: I don Not know ? Probable before 

URI query part ```?page[offset]="90"&page[limit]="30"``` leads to joomla internal object

```json
{
"page":
    {
        "offset":"90",
        "limit":"30"
    }
}
```

Which will then used to create the response pagination links
```json
{
    "links": {
        "self": "http://127.0.0.1/api_6x/api/index.php/v1/config/application?page%5Boffset%5D=90&page%5Blimit%5D=30",
        "first": "http://127.0.0.1/api_6x/api/index.php/v1/config/application?page%5Boffset%5D=0&page%5Blimit%5D=30",
        "previous": "http://127.0.0.1/api_6x/api/index.php/v1/config/application?page%5Boffset%5D=60&page%5Blimit%5D=30"
    },
}    
```


Using unencoded URL ```http://127.0.0.1/api_6x/api/index.php/v1/config/application?page[offset]=90&page[limit]=30``` leads to

```json
{
    "links": {
        "self": "http://127.0.0.1/api_6x/api/index.php/v1/config/application?page[offset]=90&page[limit]=30",
        "first": "http://127.0.0.1/api_6x/api/index.php/v1/config/application?page%5Boffset%5D=0&page%5Blimit%5D=30",
        "previous": "http://127.0.0.1/api_6x/api/index.php/v1/config/application?page%5Boffset%5D=60&page%5Blimit%5D=30"
    },
}
```

getModule 

Where does the module come from ?

API module 
First, it is checked whether the module name matches an API module within the namespace. It is then returned.  

Administrator moduloe
If no API module is found a 'administrator' module is searched 

Search base path for modules
The namespace part ```"Example\Component\Example"``` is extended with either '/Api' or '/Administrator' as the base path for the search.

The API or Administrator can be forced by naming it in the call

```php
$modelFile = $this->getModel('xxx', 'api');
$modelFile = $this->getModel('xxx', 'administrator');
```


First char of prefix will be set to upper case
