### modelState

Assign things like limit and other state variables 


```php
    /**
     * @param   null  $id
     *
     * @since  5.0.10
	 */
    /* <br /> error: use following to create an error with prepended error message
    public function displayItem(int|null $id = null)
    /**/
    public function displayItem($id = null)
    {
        // Set the id as the parent sets it as int
        $this->modelState->set('id', $this->input->get('id', '', 'string'));

        return parent::displayItem();
    }
```

### JsonApi.php: prepareItem

Overwrite base prepareItem() if the request result data has no id variable set, 
for example when the data is not collected from a table.
Then set the item->id to a dummy id like the example below

```php
/**
* Prepare item before render.
*
* @param   object  $item  The model item
*
* @return  object
*
* @since   4.0.0
*/
protected function prepareItem($item)
{
    // Media resources have no id.
    $item->id = '0';

   return $item;
}
```
