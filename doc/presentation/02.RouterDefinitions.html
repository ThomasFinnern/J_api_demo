API Route definitions overview

URL structure for Joomla API calls (I)


Uniform Resource Locator structure abbreviated:

www.example.com/documentation/index.html?p1=A&p2=B#ressource
\_____________/\_______________________/\________/\________/
       |                   |                 |         |
      host                path             query    fragment
Joomla API example: 

example.com/api/index.php/v1/config/application?page[offset]=30&page[limit]=30
\__________/\____________/\___________________/\_____________________________/
     |            |                 |                        |
    host       api path         endpoints                  query

URL structure for Joomla API calls (II)

   |     Joomla API example:


example.com/api/index.php/v1/config/application?page[offset]=30&page[limit]=30
\__________/\____________/\___________________/\_____________________________/
     |            |                 |                        |
    host       api path         endpoints                  query

Path:

  • Api path:    /api/index.php/                -> tells that we address the webservice API
  • Endpoints:  v1/config/application  -> routes to address functionality

Query:

  • pagination:   page[offset]=30&page[limit]=30
  • filter:             filter[catid]=2&filter[state]=1
  • sorting:         list[ordering]=created&list[direction]=desc
  • fields:            fields[articles]=title,catid,state

Special characters like '[', ']' must be converted like in other HTML queries
