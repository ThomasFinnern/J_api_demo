URL structure for Joomla API calls

Joomla API form: 

example.com/api/index.php/v1/config/application?page[offset]=30&page[limit]=30
\__________/\____________/\___________________/\_____________________________/
     |            |                 |                        |
    host       api path         endpoints                  query

Api path:

  • /api/index.php/                -> webservice starting in web site `/api` folder

Endpoints:

  •  v1/config/application  -> routes to address functionality

URL structure for Joomla API calls

Joomla API form: 

example.com/api/index.php/v1/config/application?page[offset]=30&page[limit]=30
\__________/\____________/\___________________/\_____________________________/
     |            |                 |                        |
    host       api path         endpoints                  query

Query:

  • pagination:   page[offset]=30&page[limit]=30
  • filter:                 filter[catid]=2&filter[state]=1
  • sorting:           list[ordering]=created&list[direction]=desc
  • fields:                fields[articles]=title,catid,state

Special characters like '[' and ']' must be converted to '%5B' and '%5D' ...
like in other HTML queries

GET v1/secondhand/books (lists all books with variables)

Example CURL: 
                
            curl -s --show-error
            -X GET "http://127.0.0.1/web_page/api/index.php/v1/secondhand/books"
            -H "Content-Type: application/json" -H "X-Joomla-Token:  ..."
Example HTTP: 
                
            GET http://127.0.0.1/web_page/api/index.php/v1/secondhand/books
            Accept: application/vnd.api+json
            Content-Type: application/json
            X-Joomla-Token:  ...

POST v1/secondhand/books (part 1 / curl)

Example CURL: 
                
curl -s --show-error
   -X POST "http://127.0.0.1/web_page/api/index.php/v1/secondhand/books"
   -d "{
        \"titl\":\"My book\",
        \"isbn\":\"12-3456-78-90\",
        \"$author\":"john breeze\",
        \"description\":\"The next book i write\",
        \"published\":1
    }"
   -H "Content-Type: application/json" -H "X-Joomla-Token:  ..."

POST v1/secondhand/books (part 2 / HTTP)

Example HTTP: 
                
###
POST http://127.0.0.1/web_page/api/index.php/v1/secondhand/books
Accept: application/vnd.api+json
Content-Type: application/json
X-Joomla-Token:
{
   "title": "My book",
   "isbn": "12-3456-78-90",
   "author": "john breeze",
   "description": "The next book i write",
   "published": 1
}

PATCH v1/secondhand/books/:id

Example CURL: 
                
curl -s --show-error
   -X PATCH "http://127.0.0.1/web_page/api/index.php/v1/secondhand/1/books"
   -d "{
        \"published\":-2,
        \"isbn\":\"1234-4567-8890\"
    }"
   -H "Content-Type: application/json" -H "X-Joomla-Token:  ..."
Example HTTP: 
                
###
PATCH http://127.0.0.1/web_page/api/index.php/v1/secondhand/books/1
Accept: application/vnd.api+json
Content-Type: application/json
X-Joomla-Token:

{
    "published": -2,
    "isbn": "1234-4567-8890",
}
